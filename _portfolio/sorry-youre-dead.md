description: "A 2D Stardew-inspired game set in the zombie apocalypse, made with a 6-person team for my Game Design Studio 1 class, I am only going over the parts I made in the post. As the environment artist, I made the tile art, sprites, and shaders that bring the world to life, and I also coded some of the game's systems and UI. I did not make the character sprites. I also used this project as an excuse to finally learn pixel art, so I hope you enjoy it."
